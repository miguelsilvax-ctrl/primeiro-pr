# primeiro-pr

Repositório de prática para aprender o fluxo de Pull Request no GitHub.

## Objetivo

Este repositório existe para praticar o ciclo completo de contribuição:

1. Fazer um fork ou clonar o repositório
2. Criar um branch para a mudança
3. Fazer commit das alterações
4. Abrir um Pull Request
5. Receber revisão e fazer merge

## Como contribuir

```bash
# Clone o repositório
git clone https://github.com/miguelsilvax-ctrl/primeiro-pr.git

# Crie um branch para sua mudança
git checkout -b minha-melhoria

# Faça suas alterações, depois commit
git add .
git commit -m "descrição da minha melhoria"

# Envie o branch e abra um PR
git push origin minha-melhoria
```
